This organization contains individually authored, research-oriented software modules that support human-centered computing, robotics, and intelligent systems development.
These projects serve as the technical backbone for experimental systems, robotics workflows, and integration frameworks developed in your research and teaching.

## 🧩 Current Projects

### 1️⃣ MQTT–ROS Bridge
A lightweight Java-based communication layer that connects **MQTT ecosystems** with **ROS/ROS2 topics**.  
This tool enables distributed applications, external systems, and lightweight IoT devices to interact seamlessly with robotic platforms and ROS-based environments.

**Key Capabilities**
- Publish/subscribe across MQTT and ROS2  
- JSON-based message translation  
- Simple API for integration into HCI and robotics prototypes  

### 2️⃣ Universal Robotics Tools
A set of Java utilities and abstractions for interacting with **Universal Robots e-Series** platforms.  
Designed to simplify teaching, experimentation, and real-time control.

**Features**
- URScript command helpers  
- RTDE communication utilities  
- Simulation-friendly interfaces  
- Tools for teleoperation and HRI research
